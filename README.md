# 🎓 ABOUT THE PROJECT

**Student Management System** is a Java console application built to practice **Object-Oriented Programming**.

It allows users to manage student records through a simple menu-driven interface.

```text id="xj7f1p"
       STUDENT
          │
   ┌──────┼──────┐
   ▼      ▼      ▼
  ADD   SEARCH  VIEW
          │
          ▼
        DELETE
```

👨‍🎓 Add Student

# 🧠 OOP CONCEPTS USED

| Concept       | Implementation           |
| ------------- | ------------------------ |
| Class         | `Student`                |
| Object        | Student objects          |
| Constructor   | Initializes student data |
| Encapsulation | Private variables        |
| Methods       | Student operations       |
| ArrayList     | Stores student objects   |

### Object Flow

```text id="3w1c7k"
Student Class
     │
     ▼
Constructor
     │
     ▼
Student Object
     │
     ▼
ArrayList<Student>
     │
     ▼
Management System
```

# 🚀 HOW TO RUN

### Clone

```bash id="a9w7qe"
git clone https://github.com/YOUR-USERNAME/Student-Management-System.git
```

### Compile

```bash id="g2p4wy"
javac Student.java StudentManagementSystem.java
```

### Run

```bash id="m9c6ka"
java StudentManagementSystem
```
